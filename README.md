## 📂 Structure des Branches
Pour ce projet, j'ai adopté une méthodologie de travail professionnelle avec Git :
* `main` : Version stable et déployée.
* `develop` : Branche d'intégration des fonctionnalités.
* `feat/` : Branches temporaires pour chaque nouvelle fonctionnalité (ex: `feat/navbar`, `feat/footer`).
